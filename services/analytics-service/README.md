# analytics-service

Service phụ trách phân tích dữ liệu và cung cấp số liệu cho dashboard.

## Phạm vi

- Tổng hợp dữ liệu người dùng, sản phẩm, đơn hàng, đánh giá và hành vi.
- Tạo chỉ số dashboard cho admin.
- Phục vụ phân tích hiệu quả recommendation và chatbot.

## Chỉ số dự kiến

- Doanh thu, số đơn hàng, tỷ lệ chuyển đổi.
- Sản phẩm xem nhiều, mua nhiều, thêm giỏ hàng nhiều.
- Từ khóa tìm kiếm phổ biến.
- Bộ lọc được dùng nhiều.
- Tỷ lệ click vào sản phẩm gợi ý.
- Precision@K, Recall@K, Coverage, Diversity nếu dữ liệu phù hợp.
